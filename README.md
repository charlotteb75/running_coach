## AI running coach

This application plans a user's daily training through a LLM depending on their running background/history, and their goals.

The user can give feedback on their training everyday to have the LLM adapt their planning.

The app retrieves the user's Garmin watch data through the Garmin API so that they can follow your statistics.

The app's tasks are monitored in a specific page (LLM requests and Garmin data retrieval).
